# Discord Bot

A records and leaderboard bot for the [Zeepkist Discord server](https://discord.gg/zeepkist) using data from Zeepkist GTR.

## Recommended IDE Setup

[VSCode](https://code.visualstudio.com/)

## First-time Project Setup

```sh
bun install
```

### Run Service

```sh
bun run start
```


### Lint with Biome

```sh
bun run check # Only report linting errors
bun run check:fix # Automatically resolve fixable errors
```

### Run Tests

```sh
bun run test
```

### Run Tests with Coverage

```sh
bun run coverage
```
